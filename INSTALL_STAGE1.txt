PSYVIEW FIT-FUNCTION UI — STAGE 1 (V2)
======================================

This version DOES NOT use pytest during local installation.

PURPOSE
-------
First prove that the equation interface is visible and usable.
Do not connect arbitrary equations to fitting yet.

WINDOWS DEVELOPMENT INSTALL
---------------------------
1. Close PsyView.
2. Extract this ZIP into the ROOT of Access_PNAS_psy_data.
3. Double-click:
       INSTALL_FIT_FUNCTION_UI.bat

   The installer:
   - edits only app.py, help_screen.py and the CI workflow;
   - syntax-checks the changed/new Python;
   - runs a fresh-interpreter import/wiring check;
   - does NOT run pytest;
   - restores the original edited files automatically if verification fails.

4. You want:
       INSTALL SUCCESSFUL

5. Start PsyView normally:
       run_psyview.bat

6. Open the lateral dataset and go to:
       Subject -> Luminance/profile

7. The right panel must begin with:
       FIT FUNCTION
       ACTIVE FIT
       Thesis Eq. B.25

8. Press G.
   You must see:
       FIT FUNCTION — INTERFACE PREVIEW

9. Enter, for example:
       A*cos(k*x+phi)
   and:
       A; k; phi

10. Apply it. The right panel must say:
       CUSTOM PREVIEW — NOT FITTED

11. Press F.
    The existing thesis Eq. B.25 fit must still work exactly as before.

IMPORTANT
---------
This is only a development installation step for Alexander while the feature
is being built. Once the feature is committed to the repository, ordinary
users will NOT run this installer.

Normal end-user Windows workflow remains:
    download/extract repository -> double-click run_psyview.bat -> PsyView opens

Normal users do not need pytest, PowerShell, pip commands or this installer.
