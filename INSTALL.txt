PsyView installation
====================

These instructions replace the older patch-copy notes.
Use the current checkout as a whole; do not replace individual plotting files.

Python: minimum 3.12; standard CPython 3.13 recommended.

Windows 10/11:
  Install Python from https://www.python.org/downloads/windows/
  Run run_psyview.bat

macOS Intel / Apple Silicon:
  Install the Python 3.13 macOS universal2 installer from python.org.
  In Terminal, cd into the extracted/cloned PsyView folder, then run:
    chmod +x run_psyview.sh
    ./run_psyview.sh
  Alternatively: sh run_psyview.sh
  Homebrew is not required.

Linux:
  Install Python 3.12+ with venv/pip support, then: sh run_psyview.sh

First run creates .venv and installs the project. Unchanged later launches work
without pip/network access. Do not transfer .venv between machines or platforms.
Select your separate empirical repository in the folder browser.

For manual installation, dataset/export paths, GUI/Tk troubleshooting and
Apple Silicon details, see README.md, section "Running PsyView".
Dependency audit and platform verification notes are in PORTABILITY.md.
