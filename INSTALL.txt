PsyView fixed-row axes HOTFIX
=============================

You do NOT need to revert anything else.

Replace only:

    src/psyview/app.py

WHY IT CRASHED
--------------
The previous fixed-row-axes patch accidentally generated two methods at the
wrong indentation level:

    _prepare_plot_with_row_axes(...)
    _legend_text(...)

Python accepted the file as syntactically valid, but they were no longer
methods of class PsyView. That meant opening a dataset failed when PsyView
tried to call the new shared-row-axis renderer.

THIS HOTFIX
-----------
Only corrects that class structure. It keeps the intended features:

    - fixed x/y ranges across sibling conditions in a hierarchy row
    - box plots keep categorical/local x but share y across siblings
    - min/middle/max y ticks
    - AXES information in the right-hand key
    - compact breadcrumb hierarchy
    - all existing lateral + PNAS behavior

No empirical data or GitHub repositories are modified.

VALIDATION
----------
The replacement file was:
    1. Python syntax compiled
    2. parsed with Python AST
    3. checked to confirm redraw(), _prepare_plot_with_row_axes(),
       _legend_text(), and display_spec() are direct PsyView methods

---
