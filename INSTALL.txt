PsyView always-visible y-axis scale ticks
========================================

REPLACE:
    src/psyview/plotting/axes.py
    src/psyview/plotting/terminal.py
    src/psyview/plotting/matplotlib_plots.py

OPTIONAL TEST:
    tests/test_axis_anchor_ticks.py

WHAT CHANGES
------------
This is a GLOBAL plotting change, not a box-plot special case.

Every ordinary numeric Y AXIS in PsyView now explicitly displays:

    displayed minimum
    displayed middle
    displayed maximum

For a linear y-axis:
    middle = (min + max) / 2

For a logarithmic y-axis:
    middle = sqrt(min * max)

The latter is the true visual midpoint of a log axis.

WHY
---
Previously, Plotext/Matplotlib could choose or thin major ticks differently as
the y-range changed. On some tight ranges this made labels appear/disappear,
which made it hard to tell whether two successive conditions were using the
same numerical scale.

Now the user can always read the actual displayed scale from three anchored
labels.

SCOPE
-----
Because the policy lives in the shared renderer/axis layer it applies to:

    lateral sensitivity profiles
    lateral threshold box plots
    PNAS/CSF plots
    PNAS threshold box plots
    staircase trajectories
    PSF/ISF plots
    future PlotSpec-based adapters

Custom categorical/user-specified ticks still take priority.

X-axis behaviour is otherwise unchanged.

TUI and Matplotlib use the same policy.

No scientific calculations, thresholds, fits, data, or axis limits are changed.
Only the major y-axis tick labels are made deterministic and persistent.

RUN
---
    .\run_psyview.bat
