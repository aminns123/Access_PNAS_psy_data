1. RIGHT-HAND TUI LEGEND
------------------------
The Plotext legend is removed from inside the graph and displayed in a
separate key panel immediately to the right.

It is formatted as two visual columns:
    symbol   series name

Example:
    ●   Lateral sensitivity
    ┃   spread / 2
    ━━  Diagnostic Eq. B.25 fit
    ×   Excluded from diagnostic fit

Matplotlib is unchanged.

2. 200-cd/m² LATERAL PROFILE FIX
--------------------------------
The earlier adapter made a wrong global assumption:

    if storage_script_active_exclusions exists anywhere:
        keep only that candidate everywhere

That silently removed valid conditions whose selected archived exclusion
candidate has a different name.

The public archive actually contains:
    P01 L010-L050  -> storage_script_active_exclusions
    P01 L200       -> recorded_exclusion_list
    P02-P04        -> no_exclusions

Each condition has exactly ONE selected profile candidate already.

The new adapter therefore:
    - keeps every condition's deposited candidate
    - validates exactly one candidate per condition
    - validates profile row counts against condition_summary.profile_positions

This restores P01 200 cd/m² and prevents the same class of silent omission.

3. MANUAL POINT EXCLUSION FROM DIAGNOSTIC FIT
---------------------------------------------
At lateral Subject -> Luminance:

    F       enable fit
    E       enter point-edit mode
    <- / -> move the diamond cursor
    Enter   exclude/re-include that point
    C       clear exclusions
    E       leave point-edit mode

Excluded data remain visible and are marked red ×.
They are removed ONLY from the diagnostic fit calculation.
Nothing is written to the empirical repository.

Exclusions are session-only and tracked separately per condition.

4. WHAT FIT IS BEING DONE?
--------------------------
The current diagnostic fit is NOT an unweighted ordinary curve fit.

It uses:
    sigma_i = max(full spread_i, 0.05)

and minimizes:
    sum [ (model_i - data_i) / sigma_i ]^2

This is error-weighted nonlinear least squares.

For independent Gaussian observations with fixed sigma_i, minimizing that
quantity is mathematically equivalent to maximizing the Gaussian likelihood,
because the log(sigma_i) terms do not depend on the model parameters.

So the best description is:
    "error-weighted nonlinear least squares (Gaussian MLE-equivalent for
     fixed supplied sigma)"

It is still intentionally described as a NEW DIAGNOSTIC FIT rather than the
historical archived fit, because the historical fit/input linkage and exact
old fitting sequence are not fully certified.
