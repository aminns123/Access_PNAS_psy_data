PsyView SAFE declarative-axis fix
=================================

This replaces the previous declarative-axis patch that made some plots appear
empty or extremely compressed.

REPLACE:
    src/psyview/app.py
    src/psyview/plotting/axes.py
    src/psyview/data/config.py
    src/psyview/ui/help_screen.py
    src/psyview/configs/pnas_psychophysics.yaml
    configs/pnas_psychophysics.yaml
    src/psyview/configs/lateral_sensitivity.yaml
    configs/lateral_sensitivity.yaml

OPTIONAL:
    tests/test_safe_declarative_axes.py

ROOT CAUSE FIX
==============
The previous declarative patch took each sibling plot's already-rounded /
already-padded limits and then combined and rounded those limits again.

That can progressively enlarge a hierarchy-row range and make the actual data
occupy only a tiny fraction of the TUI plotting area.

This version starts again from the LAST KNOWN-GOOD fixed-row-axis code and
changes one important rule:

    collect raw plotted sibling values
        -> union raw values once
        -> calculate one readable row limit
        -> apply YAML preferred/rounding policy once

There is no repeated union of padded limits.

CSF DEFAULT
===========
PNAS CSF remains declarative, not renderer-hard-coded:

    y:
      scale: log
      limits: row
      rounding: decades
      preferred_min: 10
      preferred_max: 1000

Examples:

    row max 850, row min 18  -> 10 .. 1000
    row max 850, row min 8   -> 1  .. 1000
    row max 1800             -> 10 .. 10000

Soft bounds never clip data.

USER SCALE CONTROLS
===================
    X   toggle numeric X log/linear
    Y   toggle Y log/linear

Press the same key again to return to YAML/PlotSpec defaults.

A categorical box-plot X axis cannot be toggled because log/linear scaling is
not meaningful for category positions.

If the user temporarily changes a configured log axis to linear, log-specific
preferred bounds (for example CSF 10..1000) are not forced onto the linear
view.

ROW CONSISTENCY
===============
The existing fixed-row rule is retained:

    all sibling plots at a hierarchy row use the same axis range.

For categorical box plots:
    X remains local/categorical
    Y is shared across sibling selections.

RIGHT-HAND AXIS KEY
===================
The key continues to show:

    X meaning
    X range or category values
    X scale + source

    Y meaning
    Y range
    Y scale + source

    fixed-row scope

VALIDATION
==========
The patch is syntax checked, AST checked to ensure all app methods are actually
inside class PsyView, YAML parsed, and the requested CSF limit examples are
tested directly.

No empirical data or repositories are modified.

RUN
===
    .\run_psyview.bat
