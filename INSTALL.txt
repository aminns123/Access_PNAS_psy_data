PsyView patch: final Staircase row + red fits + N-sensitive threshold box plot
=============================================================================

REPLACE:
    src/psyview/ui/hierarchy.py
    src/psyview/data/lateral_sensitivity.py
    src/psyview/analysis/lateral_interactive.py
    src/psyview/plotting/lateral_plots.py
    src/psyview/plotting/pnas_plots.py

OPTIONAL TEST:
    tests/test_lateral_threshold_boxplot.py

1) FINAL STAIRCASE SELECTOR ROW
-------------------------------
Hierarchy now uses a vertical scroll container and explicitly scrolls the
active row into view. At the final lateral level you should see the boxed
STAIRCASE row and the selected S1/S2/S3/S4-style item, not merely have the
plot change invisibly while pressing left/right.

2) FIT CURVES ARE RED
---------------------
Diagnostic lateral Eq. B.25 fits are now red.
The CSF current-helper fitted/interpolated curve is also red so "fit/curve"
has a consistent visual convention.

3) EXPERIMENT LEVEL IS NOW A THRESHOLD BOX PLOT
------------------------------------------------
Lateral hierarchy remains:

    Subject
      -> Luminance
        -> Position
          -> Experiment
            -> Staircase

At Experiment level, PsyView no longer overlays all staircase trial
trajectories. Instead it shows a descriptive box plot of the INCLUDED
per-staircase thresholds for that selected Base/Flanker experiment:

    box       = Q1 to Q3
    centre    = median
    whiskers  = observed min to max
    dots      = individual included staircase thresholds
    diamond   = arithmetic mean threshold actually used for sensitivity
    red x     = excluded staircase threshold(s), if present

The box is descriptive, not a confidence interval.

At Staircase level, the original individual trial trajectory + reversals view
is retained.

INTERACTIVE N
-------------
When you switch to interactive analysis and change N, the Experiment-level
box plot is rebuilt from the newly recomputed geometric-mean final-N
threshold for every included staircase.

So the visual chain is now:

    choose N
      -> one threshold per staircase
      -> threshold distribution / box plot changes
      -> arithmetic mean threshold changes
      -> sensitivity changes

This is exactly separate from the individual Staircase view below it.

RUN
---
    .\run_psyview.bat

Suggested check:
    Lateral
      -> Subject
      -> Luminance
      -> Position
      -> Experiment

Confirm box plot.

Then:
    A
    Enter   (interactive)
    left/right on N

Confirm the box changes.

Then:
    Down

Confirm the STAIRCASE selector row is visible and boxed, and left/right moves
visibly among individual staircases while the trial/reversal plot changes.
