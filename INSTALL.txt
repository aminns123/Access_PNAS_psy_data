PsyView — right-side View options panel
=======================================

TARGET
------
Current software repository:
    https://github.com/aminns123/Access_PNAS_psy_data

This package does NOT write to GitHub and does NOT touch either empirical
data repository.

WHAT CHANGES
------------
- Adds one visible footer control: V = View.
- X and Y remain functional compatibility shortcuts but are hidden from the
  footer.
- V temporarily replaces the right-side AXES/KEY text with a keyboard-first
  View table while leaving the plot itself visible.
- View controls:
      Up / Down    select a setting
      Left / Right cycle Scale or Limit scope
      Enter        edit a numeric bound or activate/reset
      Esc or V     close View
- Numeric bounds accept:
      -1
      1
      0.001
      2.5
      1e3
      Auto
- Invalid/NaN/infinite bounds, min >= max, and non-positive log bounds are
  rejected without changing the last valid view.
- Manual values are session-only and scoped to hierarchy level/view type.
- Categorical X axes skip/disable X Scale/Minimum/Maximum.
- Limit scope offers:
      Default
      Data
      Row
- Reset to defaults clears the current level's temporary scale, bounds and
  scope overrides.
- Existing automatic axis science remains underneath the View layer:
      dataset config
        -> empirical data / shared-row automatic limits
        -> temporary user overrides
        -> renderer
- Fits still do not determine automatic limits.

WHY app.py USES A PATCHER
-------------------------
The project has recently received important Codex fixes. Replacing app.py with
an older full copy would risk reverting them.

Instead, apply_view_options_patch.py is conservative:
- it expects exact blocks from the current GitHub app.py;
- it prepares all edits in memory first;
- if any expected block differs, it aborts without writing app.py;
- on success it creates:
      src/psyview/app.py.pre_view_options.bak

INSTALL — WINDOWS
-----------------
1. Extract this ZIP into the ROOT of Access_PNAS_psy_data.
   Allow the supplied source/help/test files to be added/replaced.

2. From the repository root run:

      .\.venv\Scripts\python.exe apply_view_options_patch.py

   If you do not have the venv yet:

      python apply_view_options_patch.py

3. Start PsyView normally:

      .\run_psyview.bat

INSTALL — macOS / Linux
-----------------------
After extracting into the repository root:

      ./.venv/bin/python apply_view_options_patch.py

or:

      python3 apply_view_options_patch.py

Then use the repository's normal Unix launcher.

OPTIONAL TESTS
--------------
Windows:

      .\.venv\Scripts\python.exe -m pytest tests/test_view_state.py tests/test_display_refinements.py

macOS/Linux:

      ./.venv/bin/python -m pytest tests/test_view_state.py tests/test_display_refinements.py

MANUAL CHECK
------------
1. Open a normal numeric plot and press V.
2. Confirm the right side says VIEW and the plot remains visible.
3. Use Up/Down to highlight Y minimum.
4. Press Enter, type -1, then Enter.
5. Edit Y maximum to 1.
6. Confirm the graph redraws at -1 -> 1.
7. Press Esc and confirm the normal AXES/KEY panel returns.
8. Confirm arrows navigate the hierarchy again.
9. Re-open V and use Reset to defaults.
10. On a box plot, confirm X controls show Categorical and are skipped.
11. On non-positive empirical data, confirm Log is refused cleanly.
12. Move left/right through sibling conditions and confirm manual settings
    persist at that hierarchy level.

ROLLBACK
--------
The successful patch leaves:

      src/psyview/app.py.pre_view_options.bak

To restore app.py, copy that backup over src/psyview/app.py.

The two new UI modules are inert if app.py no longer imports them.
