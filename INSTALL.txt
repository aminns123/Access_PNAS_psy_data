===================================================================

1. HIERARCHY / UP-ARROW FIX
---------------------------
The previous VerticalScroll hierarchy could capture arrow keys when the fifth
STAIRCASE row appeared.

Hierarchy is now a normal Vertical container again. There is no extra vertical
scrollbar. The app gives it enough room for five boxed rows.

Expected:
    at Staircase level, the boxed selector remains visible;
    Up returns to Experiment normally.

2. BOX-PLOT Y LIMITS
--------------------
Position- and Experiment-level threshold box plots now inherit the y-axis range
from the raw trial-level normalized contrast values for that same selection.

So the box plot no longer zooms tightly around only the thresholds. It is shown
on the same underlying contrast scale as the staircase trajectories, making
changes across conditions easier to judge in context.

This is implemented generically via PlotSpec xlim/ylim overrides.

3. POSITION LEVEL = GROUPED BOX PLOTS
-------------------------------------
The old connected Base/Flanker component plot is removed.

At Position level PsyView now groups the individual staircase thresholds by
the repository's experiment/category column and draws them side by side.

The category strings are NOT hard-coded. If a repository stores:
    base / flanker
you see:
    base     flanker

If a compatible repository stores:
    control / surround
you see:
    control  surround

At Experiment level the exact same generic helper naturally shows one box for
the selected category.

At Staircase level the individual trial/reversal trajectory remains unchanged.

4. INTERACTIVE N
----------------
In interactive mode the box distributions are rebuilt from the recomputed
final-N threshold of every staircase. Changing N therefore changes both the
side-by-side Position boxes and the single Experiment box.

5. FIT COLOUR CONVENTION
------------------------
Terminal and Matplotlib now enforce a generic convention:
    fitted/model line curves -> red

This is renderer-side and therefore also catches future line series labelled as
a fit/curve without recolouring measurement points such as "Included in fit".

6. GENERALISATION
-----------------
A reusable module is added:
    src/psyview/plotting/boxplots.py

It knows only:
    category column
    numeric value column
    optional inclusion column
    optional reference y values
    labels/metadata

It does not know about Base, Flanker, lateral sensitivity, or psychophysics.
