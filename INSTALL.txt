PsyView compact breadcrumb hierarchy patch
==========================================

REPLACE:
    src/psyview/ui/hierarchy.py
    src/psyview/app.py
    src/psyview/ui/help_screen.py

WHAT CHANGES
------------
Instead of keeping every previous hierarchy level as a full boxed row, PsyView
now collapses the selected path into one compact breadcrumb.

Example at Staircase level:

    PATH: P01 | 40 | 0.768 | base | S1

    STAIRCASE
    [ S1 ] [ S2 ] [ S3 ] [ S4 ]

Only the CURRENT level remains as a full selector row.

This means:
    - the hierarchy height stays constant as you move deeper
    - the plot no longer gets pushed downward
    - no vertical hierarchy scrollbar grows with depth
    - Up / Down continue to move between hierarchy levels
    - Left / Right continue to change the current value
    - the breadcrumb tells you exactly which branch you are on

GENERALITY
----------
The breadcrumb does not know about Subject, Luminance, Position, Experiment,
or Staircase. It simply displays the selected values from whatever hierarchy
the active adapter provides.

So a future dataset might show:

    PATH: mouse_07 | session_3 | control | trial_12

without any PsyView UI changes.

RUN
---
    .\run_psyview.bat

Suggested check:
    move from Subject all the way down to Staircase.

The plot should remain at essentially the same vertical position throughout,
while the path changes from something like:

    PATH: P01

to:

    PATH: P01 | 40

to:

    PATH: P01 | 40 | 0.768

to:

    PATH: P01 | 40 | 0.768 | base

to:

    PATH: P01 | 40 | 0.768 | base | S1
