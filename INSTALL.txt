PsyView CSF error-bar patch
===========================

PURPOSE
-------
Add descriptive error bars to archived CSF points using the list of included
individual staircase thresholds at each spatial frequency.

SCIENTIFIC DEFINITION
---------------------
The archived CSF point is unchanged:

    mean_threshold = arithmetic mean of included staircase thresholds
    sensitivity = 1 / mean_threshold

The new bar is descriptive across-staircase variability:

    sd_threshold = sample SD of included staircase thresholds (ddof=1)

    lower sensitivity = 1 / (mean_threshold + sd_threshold)
    upper sensitivity = 1 / (mean_threshold - sd_threshold)

This keeps the archived CSF point exactly unchanged and propagates the
threshold variability through the same reciprocal sensitivity definition.
The bars are explicitly labelled as descriptive across-staircase variability,
NOT confidence intervals.

Only primary-included staircases contribute. Frequency points excluded from the
CSF fit still retain their measurement/error bar because the exclusion concerns
the fit, not the underlying staircase-derived observation.

COPY / REPLACE
--------------
REPLACE:
    src/psyview/plotting/pnas_plots.py
    src/psyview/data/pnas_psychophysics.py

OPTIONAL NEW TEST:
    tests/test_csf_errorbars.py

No pyproject.toml change is needed.

TEST
----
Launch normally:

    .\run_psyview.bat

Open the CSF/PSF dataset and go:
    Subject -> Luminance

The CSF points should now have vertical error bars.

The existing lateral-sensitivity error bars are untouched.
