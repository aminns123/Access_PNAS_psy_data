PsyView TUI error-bar alignment patch
=====================================

PURPOSE
-------
Improve terminal/TUI uncertainty bars without changing any scientific values
or Matplotlib output.

WHAT CHANGES
------------
Two-point vertical intervals are now drawn in the terminal as:

    ━
    ┃
    ┃   ●   <- measurement scatter is drawn last/on top
    ┃
    ━

rather than as a Plotext braille line.

Why:
Plotext's braille rasterisation can place a two-point vertical line in a
neighbouring sub-cell from the scatter point. The new renderer samples the
interval at the exact same scientific x coordinate as the point and uses heavy
vertical/cap glyphs. This makes the bars:
  - better centred on the scatter point
  - visually heavier/more distinctive
  - still compatible with linear and log y axes

The shared PlotSpec remains unchanged, so Matplotlib output is untouched.

REPLACE
-------
    src/psyview/plotting/terminal.py

OPTIONAL NEW TEST
-----------------
    tests/test_terminal_intervals.py

No dependency or pyproject.toml change is required.

RUN
---
    .\run_psyview.bat

Check:
  CSF Subject -> Luminance
  lateral Subject -> Luminance
  PSF Subject level

The same improvement applies to vertical percentile/error intervals in the TUI.
